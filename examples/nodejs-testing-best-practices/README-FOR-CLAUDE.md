# Razor context pack — nodejs-testing-best-practices (Claude Code layout)

Generated by Razor (https://github.com/NSmonish/razor-cli) from the repo
goldbergyoni/nodejs-testing-best-practices. Stack: Express.js / Jest / Sequelize.
Every fact is grounded in a real file in that repo (see each skill's `evidence`).

This file sits next to `pack/`, not inside it, so it never ends up in the repo
an agent works in. The A/B eval (`eval/ab/`) installs `pack/` exactly like
step 2 below.

## How to use with Claude Code (to run evals)
1. Clone the target repo:
   git clone https://github.com/goldbergyoni/nodejs-testing-best-practices
2. Copy the contents of `pack/` (including the hidden `.claude/`) into the repo
   root, e.g. `cp -R pack/. <repo>/`, so the layout becomes:
   <repo>/AGENTS.md
   <repo>/overview.md, architecture.md, workflows.md, verification.md, steering.md
   <repo>/.claude/skills/<skill>/SKILL.md   (Claude Code auto-discovers these)
   <repo>/scripts/check.sh
   <repo>/skills.index.json                 (routing manifest: name, triggers, evidence)
3. Open the repo in Claude Code (v2.1.277+). It reads AGENTS.md at root and the
   skills under .claude/skills/ automatically.
4. Ask Claude to run the eval tasks. It can use:
   - skills/run-tests  -> `jest`
   - skills/lint-fix   -> `eslint .`
   - skills/db-migrations -> `cd example-application/data-access && sequelize-cli db:migrate`
   - scripts/check.sh  -> runs lint + tests in one go

## Contents
- AGENTS.md            entry point (table of contents + essentials)
- overview/architecture/workflows/verification/steering.md  layered docs
- .claude/skills/*/SKILL.md  5 skills, each with a concrete command + evidence
- skills.index.json    machine-readable routing manifest (triggers per skill)
